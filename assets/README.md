# Assets

`icon.png` is a 512x512 mark drawn for this template: an open book under a small graph of linked notes, for
a wiki that an AI compiles from what you read. It was made in `PIL` for this repository and is MIT licensed
along with the rest of it.

Nothing from the LLM Wiki, Supabase or RustFS projects is reused, and none of them is affiliated with or
endorses this template.
